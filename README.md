# Personal Portfolio Website

This repository contains the source code for my personal portfolio website. The website presents my background, technical skills, professional experience, projects, education, achievements, and contact information.

## Project Overview

The portfolio is being developed as part of my full-stack software development coursework. It is designed to provide a clear and accessible overview of my experience as a software developer.

The website includes the following sections:

- User Profile
- About Me
- Skills
- Experience
- Additional Experience
- Projects
- Education
- Achievements
- Contact Form

## Project Objectives

The main objectives of this project are to:

- Build a structured portfolio using semantic HTML.
- Create a responsive layout for desktop and mobile devices.
- Provide accessible navigation and form controls.
- Present my experience and projects clearly.
- Apply maintainable HTML and CSS practices.
- Apply principles of project planning.
- Practice deductive reasoning and Problem decomposition techniques.
